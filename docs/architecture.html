Runtime architecture / 現況資料流 GITHUB PAGES · CLOUDFLARE WORKERS · D1 / R2 · OAUTH
前端／使用者介面 API／後端 資料庫／物件儲存 雲端 PDF 渲染 身分驗證／安全 外部服務

01 / DATA OWNERSHIP

localStorage 放瀏覽器草稿；D1 是登入後跨裝置同步的專案、條款與版本資料；R2 放私有印章圖片。Google 登入不是 Google Drive 存檔。

02 / AUTHENTICATION

Google OAuth 專案 kino-quotation 發出 ID token；Worker 驗證後簽發 QT 工作階段。OneDrive 則由瀏覽器以 MSAL 取得委派權限，直接呼叫 Microsoft Graph。

03 / DOCUMENT OUTPUT

列印在本機瀏覽器完成，不需登入。下載 PDF把已準備好的列印內容暫送 Worker，由 Chromium 轉檔後回傳；不存入 D1／R2。
