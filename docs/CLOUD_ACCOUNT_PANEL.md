# 雲端入口整合驗收（2026-11-18）

基準：正式 main `4b47d71`，獨立 release 工作樹；不發佈原開發樹的簽署／Browser Run 額度功能。

## 操作分工

- 導覽列統一「雲端與帳號」，保留待確認同步／錯誤提醒；資料庫管理不再佔用另一顆導覽列按鈕。
- Google 區分「管理專案與條款」、「檢視同步差異」及帳號管理；沿用既有差異確認、版本與刪除保護。
- OneDrive 區顯示 Microsoft 帳號、已綁定／待重連、是否選資料夾、位置及自動存檔。主按鈕在有可用帳號與目錄時才呼叫既有 saveDataToOneDrive；其他情況開既有設定視窗。右側箭頭永遠為帳號與儲存設定，不觸發儲存。
- 手機底部面板、電腦右上浮動面板；支援 Escape、焦點循環與關閉後回到入口；列印排除此面板。

## 隔離驗收

- 40/40既有單元測試通過，含公開建置白名單、雲端保護、備份與可填寫 PDF。
- tests/cloud-account-panel.cjs：390／1366px 真實編輯台，所有應用端點封閉攔截。開啟面板／管理／設定零寫入；儲存只送 OneDrive，差異檢視只讀同步端點；帳號／未選目錄／已選目錄／重新連接／登入失效、焦點、邊界與列印隱藏皆通過。截圖人工檢查手機與電腦版面。
- tests/onedrive-binding-e2e.cjs：手機選上級目錄、自動建子目錄、儲存實際 JSON；真實 handler／SQLite／模擬 Graph，原專案 sentinel 不變。
- tests/mobile-sync-mock.cjs：同步具體差異、Snackbar、印章透明度／跨格、序列化與手動 OneDrive、兩個隔離網址備份／還原通過。測試有意對隔離替身做同步寫入，不接觸正式 D1／R2／OneDrive。
- 回歸測試入口已改用雲端面板；修正既有印章測試 first() 選到隱藏版面按鈕的定位問題。沒有為此更動印章邏輯。

## 部署邊界

僅前端與文件／測試變更，Worker、Secret、SQL、資料表與儲存鍵皆不變。不查閱或改寫現有使用者資料，不開啟自動存檔、不變更現有目錄。透過既有 kinostudio/qt main → kino-quotation-editor Git 整合部署，與官網無關。

尚未驗收：實體手機觸控及真實 OneDrive 隔離檔案寫入。模擬驗收不能取代真實帳號的存檔驗收。
